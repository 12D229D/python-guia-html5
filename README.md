# Guía Interactiva de Python 3 (HTML5)

Aplicación web estática, moderna, responsive e interactiva para aprender Python 3.

## 🚀 Características Principales

* **HTML5 Semántico y Estructurado**: Organizado en secciones claras desde nivel principiante hasta conceptos avanzados.
* **Diseño Moderno & Responsive**: Estilizado con la paleta de colores oficial de Python (Azul y Amarillo) e interfaz adaptable a teléfonos, tabletas y computadoras.
* **Tema Claro y Oscuro**: Alternador de tema visual con persistencia en `localStorage`.
* **Bloques de Código Interactivos**:
  * Botones de **Copiar código al portapapeles** con retroalimentación en tiempo real.
  * Resaltado de sintaxis limpio y legible.
  * Botón **▶️ Probar en Consola** en cada sección.
* **Consola Simulada / Playground (REPL)**: Permite seleccionar y simular la ejecución de los snippets de código en tiempo real dentro de una interfaz de terminal.
* **Buscador en Tiempo Real**: Filtrado instantáneo por palabras clave y soporte para el atajo de teclado `Ctrl + K`.
* **Quiz Interactivo**: Cuestionario de evaluación al final de la guía con puntuación, soluciones en verde/rojo y opción de reinicio.

## 📁 Estructura del Proyecto

```text
python-guia-html5/
├── index.html        # Documento principal HTML5 con todo el contenido y estructura
├── css/
│   └── styles.css    # Estilos CSS3, variables de tema y responsive design
├── js/
│   └── app.js        # Lógica interactiva ES6+: buscador, terminal, quiz y copiar
└── README.md         # Documentación del proyecto
```

## 🛠️ Cómo Ejecutar

No requiere servidores ni dependencias externas de Node.js o Python.
Simplemente abre el archivo `index.html` en cualquier navegador web moderno (Chrome, Edge, Firefox, Safari).
