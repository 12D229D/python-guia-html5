🚀 1. Introducción a Python

Python es un lenguaje de programación de alto nivel, interpretado, dinámico y multiparadigma, famoso por su legibilidad y simplicidad.

¿Por qué elegir Python?

  • Sintaxis limpia: Código legible parecido al pseudocódigo inglés.
  • Versátil: Web, Ciencia de datos, IA, Automatización, Scripting y Ciberseguridad.
  • Ecosistema gigante: Más de 400,000 paquetes en PyPI (pip).

Instalación y Consola

Descarga Python desde python.org. Para verificar tu versión en la terminal:

python --version

Tu primer programa: Hola Mundo

En Python no necesitas clases complejas ni métodos main() para empezar. Solo usa la función print():

hola_mundo.py 
# Este es un comentario en Python
print("¡Hola, mundo desde Python!")

# Formato con f-strings
nombre = "Desarrollador"
print(f"¡Bienvenido a la guía, {nombre}!")

🔤 2. Fundamentos de Python

Variables y Tipos de Datos Principales

Python es de tipado dinámico. No requiere declarar el tipo de variable explícitamente.

Tipo Nombre en Python Ejemplo Descripción
int Entero edad = 25 Números enteros positivos o negativos.
float Flotante precio = 19.99 Números decimales.
str Cadena nombre = "Python" Texto encerrado en comillas simples o dobles.
bool Booleano es_activo = True Valor de verdad (True o False).
variables.py 
# Asignación de variables
edad = 28
estatura = 1.75
lenguaje = "Python"
es_genial = True

# Consultar el tipo de dato
print(type(edad))       # <class 'int'>
print(type(estatura))   # <class 'float'>

# Conversión de tipos (Casting)
numero_str = "100"
numero_int = int(numero_str)
print(numero_int + 50)  # Muestra: 150

Operadores en Python

Aritméticos

+ (suma), - (resta), * (mult), / (división flotante), // (división entera), % (módulo), ** (potencia).

Comparación

==, !=, >, <, >=, <=.

Lógicos

and, or, not.

🔀 3. Control de Flujo

Estructuras Condicionales (if, elif, else)

La sangría (indentación) de 4 espacios es obligatoria en Python para definir bloques de código.

condicionales.py 
nota = 85

if nota >= 90:
    print("Calificación: A - Excelente")
elif nota >= 80:
    print("Calificación: B - Muy Bueno")
elif nota >= 70:
    print("Calificación: C - Aprobado")
else:
    print("Calificación: Reprobado")

Bucle FOR y Bucle WHILE

bucles.py 
# Bucle For con range()
print("--- Conteo con range ---")
for i in range(1, 4):
    print(f"Iteración {i}")

# Bucle While
print("--- Bucle While ---")
contador = 3
while contador > 0:
    print(f"Cuenta regresiva: {contador}")
    contador -= 1
print("¡Despegue!")

📦 4. Estructuras de Datos

Listas (list)

Colecciones ordenadas y mutables. Se definen con corchetes [].

frutas = ["manzana", "platano", "cereza"]

Tuplas (tuple)

Colecciones ordenadas e inmutables (no se pueden modificar). Se definen con paréntesis ().

coordenadas = (10.5, -20.8)

Diccionarios (dict)

Colecciones de pares clave-valor. Se definen con llaves {}.

usuario = {"nombre": "Ana", "edad": 25}

Conjuntos (set)

Colecciones desordenadas de elementos únicos (sin duplicados).

numeros = {1, 2, 3, 3, 4} # {1, 2, 3, 4}

Ejemplo Práctico de Estructuras de Datos

estructuras.py 
# Manipulación de Listas
lenguajes = ["Python", "JavaScript", "C++"]
lenguajes.append("Rust")
print(f"Lista de lenguajes: {lenguajes}")

# Diccionario Clave-Valor
persona = {
    "nombre": "Carlos",
    "rol": "Data Engineer",
    "experiencia_años": 5
}
print(f"Rol de {persona['nombre']}: {persona['rol']}")

# List Comprehension (Comprensión de listas)
cuadrados = [x**2 for x in range(1, 6)]
print(f"Cuadrados del 1 al 5: {cuadrados}")

⚙️ 5. Funciones en Python

Las funciones se definen con la palabra clave def. Soportan parámetros por defecto, argumentos con nombre y funciones lambda.

funciones.py 
# Función estándar con parámetros por defecto
def saludar(nombre, saludo="Hola"):
    return f"{saludo}, {nombre}!"

print(saludar("María"))
print(saludar("Juan", "Buenos días"))

# Función Lambda (Anónima)
multiplicar = lambda a, b: a * b
print(f"Resultado de 4 x 5 = {multiplicar(4, 5)}")

🏛️ 6. Programación Orientada a Objetos (POO)

Python soporta POO mediante el uso de clases, métodos, constructores __init__ y herencia.

poo.py 
class Vehiculo:
    def __init__(self, marca, modelo):
        self.marca = marca
        self.modelo = modelo

    def obtener_info(self):
        return f"Vehículo: {self.marca} {self.modelo}"

# Herencia
class AutoEléctrico(Vehiculo):
    def __init__(self, marca, modelo, bateria_kwh):
        super().__init__(marca, modelo)
        self.bateria_kwh = bateria_kwh

    def estado_bateria(self):
        return f"Batería actual: {self.bateria_kwh} kWh"

# Instanciar objetos
mi_tesla = AutoEléctrico("Tesla", "Model 3", 75)
print(mi_tesla.obtener_info())
print(mi_tesla.estado_bateria())

🚨 7. Manejo de Excepciones

Gestiona errores durante la ejecución usando bloques try, except, else y finally para evitar que la aplicación falle inesperadamente.

excepciones.py 
def dividir(a, b):
    try:
        resultado = a / b
    except ZeroDivisionError:
        return "Error: No se puede dividir entre cero."
    except TypeError:
        return "Error: Ingresa números válidos."
    else:
        return f"Resultado exitoso: {resultado}"
    finally:
        print("Operación de división finalizada.")

print(dividir(10, 2))
print(dividir(5, 0))

Módulos de la Biblioteca Estándar

Python incluye potentes módulos por defecto como math, random, datetime y json.

modulos.py 
import math
import random
from datetime import datetime

print(f"Raíz cuadrada de 16: {math.sqrt(16)}")

print(f"Fecha actual: {datetime.now().strftime('%Y-%m-%d %H:%M:%S')}")
